# MINICRAFT — 웹 복셀 샌드박스

브라우저에서 바로 즐기는 마인크래프트 스타일 1인칭 복셀 게임입니다.
Three.js 이외의 외부 의존성이 없고, **텍스처·소리·지형을 모두 코드로 생성**하므로
인터넷 연결 없이 오프라인에서도 완전히 동작합니다.

## 실행 방법

`index.html` 을 **더블클릭**하면 바로 실행됩니다. (별도 서버/설치 불필요)

> 브라우저 정책상 로컬 파일에서 모듈을 쓰지 않도록 UMD 빌드로 구성했습니다.
> 혹시 실행이 안 되면 아래처럼 간단한 로컬 서버를 띄워 접속하세요.
>
> ```bash
> npx serve .        # 또는
> python -m http.server 8000
> ```
> 그리고 브라우저에서 `http://localhost:8000` 접속.

권장 환경: 데스크톱 Chrome / Edge / Firefox (WebGL2). 키보드와 마우스가 필요합니다.

## 구현된 기능

**월드**
- 16×16×72 청크 기반 무한 월드 스트리밍 (거리 기반 로드/언로드)
- 시드 기반 펄린 노이즈 지형: 대륙 · 구릉 · 리지드 산맥 · 해수면 · 해변 · 사막 · 설원
- 3D 노이즈 동굴, 광맥(석탄/철/금/다이아몬드), 자갈·흑요석 광맥
- 나무·선인장 자동 배치(청크 경계에서도 이어짐)
- 정수 키 청크 맵 + 이웃 청크 캐시로 빠른 복셀 조회

**렌더링**
- 면 컬링 + 앰비언트 오클루전(AO) + 면별 명암 + 깊이 기반 광량을 버텍스 컬러로 베이크
- 불투명 / 알파 컷아웃(나뭇잎) / 반투명(물·유리) 3개 패스
- 외부 이미지 없는 32종 16×16 픽셀 아트 아틀라스(밉맵 번짐 방지 패딩 포함)
- 낮/밤 주기(10분), 태양·달·별, 노을 색조, 거리 안개
- 부서진 블록 파티클(InstancedMesh), 화면 흔들림, 달리기 FOV

**게임플레이**
- AABB 충돌 + 중력/점프/수영/비행 물리, 물 속 저항과 화면 색조
- DDA 복셀 레이캐스트로 정확한 블록 조준·설치(플레이어와 겹침 방지)
- 손에 든 블록 뷰모델(휘두르기 애니메이션 포함)
- WebAudio로 합성한 부수기/설치/발소리/물소리
- localStorage 자동 저장(시드 + 블록 수정 내역만 저장해 용량 최소화)

## 파일 구조

```
index.html          화면 구성 및 스크립트 로드
css/style.css       UI 스타일
js/noise.js         시드 기반 펄린 노이즈 / 해시
js/blocks.js        블록 정의(28종) + 면 기하 데이터
js/textures.js      절차적 픽셀 텍스처 아틀라스 생성
js/world.js         청크 생성 · 메시 빌드 · 스트리밍 · 저장
js/player.js        이동/충돌 물리 + 복셀 레이캐스트
js/sound.js         WebAudio 효과음 합성
js/ui.js            HUD · 단축바 · 블록 목록 · 패널
js/main.js          게임 루프 · 입력 · 상호작용
vendor/three.min.js Three.js r147 (UMD)
```

## 성능 팁

프레임이 낮다면 `js/main.js` 의 `RENDER_DISTANCE` 값을 6 → 4~5 로 줄이면
청크 수와 삼각형 수가 크게 감소합니다. (거리 6 ≈ 137 청크, 약 50만 삼각형)

```js
const RENDER_DISTANCE = 6;   // 4 ~ 8
```

## 개발 메모

청크 지오메트리는 **청크 로컬 좌표(0~16)** 로 만들고 `mesh.position` 으로
청크 원점을 지정합니다. 좌표를 월드 단위로 직접 넣으면 먼 거리에서
float32 정밀도가 떨어져 블록 사이에 틈이 생기기 때문입니다.
(초기 버전에서 이 위치 지정이 빠져 모든 청크가 원점에 겹쳐 보이는 버그가 있었습니다)
